# Personal Dashboard

Statische Web-App (GitHub Pages). Kein Backend, kein Tracking. Externe Anfragen nur, wenn man in der Einkaufsliste ein Rezept einfügt: Links laufen über r.jina.ai, die Texterkennung für Screenshots wird einmalig von cdn.jsdelivr.net geladen (Bild bleibt auf dem Gerät).
Alle Einträge bleiben im Browser des Geräts (localStorage) und landen nie in diesem Repository.
